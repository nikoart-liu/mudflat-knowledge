# 滩涂拾遗 v0.2.0

从「把划线收进来」往前走了一步：可以按书做线索归纳，检索能按意思找，翻牌时有问题面和回忆支架。语言模型默认关闭，不配也能照常用。

## 如何升级

v0.1.0 **不会**自动提示这一版，请从本页下载安装包，装好后重新打开。

装上 0.2.0 之后，以后有新版本会在刊头下提示，设置 → 关于里也可以手动检查。本地卡片仍在本机数据目录，替换应用不会丢掉。

macOS / Windows 安装包尚未公证或代码签名，系统可能拦截；按提示允许即可。

## 这一版

**线索**  
打开一本书，可以把划线压成概要节点图。默认只画书名和一级；二级按需从一级上长出。证据（原卡）不画进图，在抽屉里。未启用语言模型时会引导去设置。

**语言模型与向量**  
设置里可选用 OpenAI、xAI、Ollama 或兼容 OpenAI 的接口。Key 存在本机，与微信读书 Key 分开。向量检索可单独配置，用于「意思相关」和相似卡。

**检索与翻牌**  
检索结果分成「原词命中」和「意思相关」。卡片可生成问题面（原文不动）。翻牌时若评「忘了 / 困难」，会给出回忆支架。

**书架与墙**  
书可置顶；侧栏按大类编目。书内墙有章节目次，按阅读顺序跳章。

**自动更新**  
对照 GitHub Releases 的 latest。有新版本时刊头下提示；确认后下载本机对应安装包并打开（macOS 为 dmg，Windows 为 NSIS，Linux 为 AppImage）。
