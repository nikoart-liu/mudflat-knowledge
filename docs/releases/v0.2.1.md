# 滩涂拾遗 v0.2.1

修应用内更新：下载安装包时进度会动，不再卡在 0% 后报 `error decoding response body`。

## 如何升级

v0.2.0 的更新器有这个 bug，**请从本页下载安装包**，不要等应用内「下载并安装」。装好后重新打开即可。本地卡片仍在本机数据目录，替换应用不会丢掉。

装上 0.2.1 之后，以后有新版本会在刊头下提示，设置 → 关于里也可以手动检查。

macOS / Windows 安装包尚未公证或代码签名，系统可能拦截；按提示允许即可。

## 这一版

**更新下载**  
安装包改成按块下载、按块写盘，百分比会往前走。不再用 120 秒总超时去掐大文件。下载走系统代理和 HTTP/1.1。若中途断开，会说明已下载多少，而不是丢一句英文 decode 错误。
