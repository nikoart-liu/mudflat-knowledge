## Design Specificity Verdict

高度专属：mono 两位序号 + 衬线书名（active 转斜体）+ 右缘 tabular 计数，金只花在到期徽标与 5px 新划线方点两处语义位，全直角零阴影。行为级规范偏离三处：① hover 击穿 active 左墨轨（App.css:164 `border-color: transparent` 简写，特异性 (0,3,0) > .active (0,2,0)）；② catTree 构建 `if (b.pinned) continue`（App.tsx:609），大类眉标「合计」不含置顶书；③ 两位序号 ≥100 本书时失效、四位数溢出 20px 定宽。

像素级遵规范的亮点：`.cat-sub { padding-left: 44px }` 精确等于书名列起点（16+20+8）；selection 底上单独调 `--ink-muted-deep #5f5f66`（5.13:1）保 AA。

确定性扫描：detect.mjs 对 src/App.tsx 退出码 0、`[]`，但为降级运行（缺 htmlparser2/css-select/domutils，regex 回退）；阳性对照（内联 red border + Comic Sans 合成 HTML）同样返回 `[]`，stderr 自述 findings are an undercount——零报告是工具假阴性，不可读作干净。浏览器叠加层不可用（会话无浏览器自动化工具）；回退信号为静态源码评审 + `vitest run src/sidebar.test.tsx` 5/5 通过。

## Overall Impression

目录隐喻的语法成立且执行克制。最大机会不在视觉而在两个状态盲区（检索态、读屏态目录「不存在」）与一个规模盲区（500 本书时序号、键盘路径、决策面同时失守）。

## What's Working

1. 44px 对齐执念：子类眉标缩进精确对齐书名列，「网格即秩序」落地为算术。
2. 折叠状态机完整闭环：只隐行不重排、aria-expanded、localStorage 持久化、消层兜底，5 条测试锁死。
3. AA 认真计算：hover/active 态单独墨阶保对比度。

## Priority Issues

1. [P1] 检索态抹掉全部侧栏定位 + aria 与视觉矛盾（App.tsx:796-799 星标行 className 带 `!searching` 守卫而 aria-pressed 无）。Fix：检索且范围受限时加 mono 9px 范围眉标；统一 active 与 aria-pressed 表达式。→ harden
2. [P1] 金方点与分类小字对读屏不存在（App.tsx:651/653：aria-label 在无 role span 上被 VoiceOver 丢弃；.book-cat aria-hidden 吞掉置顶/直挂行唯一分类信息）。Fix：金点 role="img"+aria-label；删非冗余行的 aria-hidden。→ harden
3. [P2] hover 击穿 active 墨轨（App.css:164 vs 166 特异性 bug）。Fix：hover 只清上/右/下边框，或补 `.side-item.active:hover { border-left-color: var(--ink) }`。→ polish
4. [P2] 键盘与目标尺寸：眉标高约 20px < WCAG 2.5.8 的 24px；无 role="tree"/roving tabindex。Fix：眉标 padding 7px 16px；↑↓ roving tabindex + type-ahead。→ harden
5. [P3] 188px 内容宽只露约 8 字；分类小字裸连字符「经济理财-理财」。Fix：书名 13px、book-no 18px、gap 6px；渲染时 replace('-', ' · ')。→ typeset

## Persona Red Flags

- Alex（键盘 power user）：侧栏对键盘关门——无 ↑↓、无 type-ahead、无全部折叠/展开；置顶需先进书再到章节头。
- Sam（a11y）：金点 aria-label 被丢弃；.book-cat aria-hidden 吞分类；500 个平铺按钮无树语义；20px 眉标难命中。亮点：aria-expanded、2px ember focus 圈。
- Riley（压力测试）：0 书空态在 list_books 返回前闪现；500 本三位序号挤 20px；置顶 churn 下方序号整体 +1 漂移；折叠恢复 ✅。
- 每日重访者（项目 persona）：问「流量」（昨日新增），树按「存量」排序——金点散落树深处，7 天后无声熄灭，日常问题靠人肉扫全树。
