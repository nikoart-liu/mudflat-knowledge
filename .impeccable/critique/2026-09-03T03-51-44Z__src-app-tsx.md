## Design Specificity Verdict

**Start here.** 视觉是为这本应用写的；话术还不是。

**LLM assessment:** 「刊物排印」在结构上已经作者化：直角纸边、两级线、宋体特权、金只点睛、翻牌清样编目大字。Operate 面上却不断用说明段给控件配音——牌背教你怎么翻、牌面教你怎么评分、设置解释顶栏按钮在哪、脑图把 HTTP 动词摊在读者眼前。看起来像文学内页，听起来像产品导览。特异性高在物，低在声。

**Deterministic scan:** `detect.mjs --json src/App.tsx` 退出码 0，**0 findings**。检测器认得的视觉禁令（圆角、阴影、渐变、emoji）仍被遵守。它看不见文案冗余、自指 chrome、接口泄漏。无假阳性。LLM 抓住的 P1 全部在检测器盲区——两边一致处是「皮是干净的」；不一致处是「嘴还在讲」。

**Visual overlays:** 无可靠的用户可见 overlay。Assessment B 无浏览器自动化，注入跳过。Fallback: `browser automation unavailable in this subagent; no user-visible overlay`。

## Overall Impression

这已经是一本排好的刊物，却在每页页脚加了编辑部说明。最大机会不是再压视觉，而是让控件自己说话：删掉与标题、按钮、状态重复的句子，只在真正的第一次和高风险处开口。

## What's Working

1. **刊物骨架已经成立。** 刊头墨线、目录序号、章头眉标、清样编目号、版权页栏线起首——chrome 在视觉上确实退后了。
2. **翻牌节奏是高峰。** 空格翻面、1–4 评分、墨条进度、19px/1.9 正文，日常回顾不需要鼠标。
3. **空态标题仍有编辑腔。** 「把微信读书的划线接到这面墙上」是产品声音，不是 SaaS 空状态；该瘦的是它下面的第二句说明书，不是刊头本身。

## Cognitive load

3 / 8 项失败 → **moderate**。

失败项：Chunking（书内章头把作者、计数、翻牌、线索、长读摊成一条）；Minimal choices（同条 >4 个可见项）；Progressive disclosure（教程与传输细节常驻主画布）。

>4 选项决策点：书内 `head-meta`（作者 / 划线 / 想法 / 章节 / 翻牌 / 线索 / 计数）；设置「四、语言模型」同时摊开供应商、地址、模型、Key、两段 hint、测试/保存/清除。

## Emotional journey

高峰在清样：牌面只有原文和评分。低谷在进入前后——入口页用「间隔重复讲究少而勤」训话，牌背/牌面再各贴一句操作说明；设置与线索把读者从书房拽进控制台。峰值被旁白削薄。

## Priority Issues

### [P1] 清样把操作说明书印在牌面上
- **What:** `.deck-back-hint`「点击或空格翻面」、`.deck-next-hint`「按你此刻的熟悉程度选择」、入口/空队列 `.review-hint`（批次解释、设置广告、「间隔重复讲究少而勤」）与标题、计数、四枚评分钮重复。
- **Why it matters:** 违反 H8，也违反「内容为王」。这是每天的主路径；每张牌都被 UI 打断一次。
- **Fix:** 删 `.deck-next-hint`。`.deck-back-hint` 只留第 1 张或收成角上 `[空格]`。入口只留「今日到期 N · 本批 M」+ 开始/返回；空队列一句「当前没有到期卡片」+ 返回。
- **Suggested command:** `$impeccable distill`

### [P1] 设置页用段落解释已经画在屏幕上的东西
- **What:** 「同步入口在顶栏。没有 Key 时按钮是关上的。」「每批翻多少张。小批次完成感更真实…」「默认关闭」+「当前未启用」+ `[关闭]` 三连；LLM 段还有 `GET /models` / `POST /chat/completions`。
- **Why it matters:** 版权页应是刊末信息，现在是 README。自指 chrome 和传输层细节既吵又不像给藏书人看的。
- **Fix:** 同步段只留上次同步时间。回顾段删 hint，留下 10/20/30。LLM 留一句隐私边界（「只发当前书的摘录，不上传整库」），状态交给选中的供应商钮；删 HTTP 动词行。
- **Suggested command:** `$impeccable clarify`

### [P2] 编辑弹层把同一句话写了三遍
- **What:** 「纳入翻牌回顾」label + 同文 `title` + `.switch-hint`「关闭后此卡不再进入回顾队列，仍保留在卡片墙与搜索中。」
- **Why it matters:** 日常补想法被一块 40px 说明书顶高。首次「移出回顾」已有确认弹层，这里不需要常驻课文。
- **Fix:** 删 `.switch-hint` 和重复 `title`。label 留下即可。
- **Suggested command:** `$impeccable distill`

### [P2] 线索页把导读和接口遥测放进刊头
- **What:** 范围行「概要节点 · 点开才看划线」；生成页「画面上只有概要，点节点才看原文」；`请求 {model} · POST {chatEndpoint}`。
- **Why it matters:** 读者要的是主题图，不是产品说明或 curl。隐私边界一句够；点节点看原文是交互，不必印出来。
- **Fix:** 删范围行和 POST 行。生成页缩成「将用本书 N 张卡片归纳主题（只发摘录）」。
- **Suggested command:** `$impeccable quieter`

### [P3] 空态第二句在复述按钮
- **What:** 空墙 body 把「到设置粘贴 / 再同步 / 可检索可翻牌」再说一遍；筛选空「筛过了墙」是内部隐喻漏出。
- **Why it matters:** 标题已经有声音，CTA 已经有动作；第二句多数是回声。
- **Fix:** 首次空态可留半句方向；有 Key 的空态删 body。筛选空改为「没有符合当前筛选的卡片」+ 清除筛选。
- **Suggested command:** `$impeccable clarify`

## Persona Red Flags

**Alex（效率用户）:** 每天翻几十张仍看见「点击或空格翻面」和「按你此刻的熟悉程度选择」；改 Ollama 模型要读两段不会上传整库的课文。墙面无键盘遍历。

**Jordan（第一次打开）:** 设置用「同步入口在顶栏」指路，却不在同步时间旁给一枚同步钮；线索页的 `POST {endpoint}` 和 `wrk-` 教程会让人以为自己进错了开发者面板。

**藏书人「林」（PRODUCT.md 的微信读书重读者）:** 「间隔重复讲究少而勤」「小批次完成感更真实」把书房变成习惯打卡 App；她要的是重遇半年前的划线，不是被教怎么用间隔重复。

## Minor Observations

- 设置「清除」Key / LLM 无确认。
- 侧栏「尚无标签」可留（低对比空指示），不是这次该砍的对象。
- 检索「只搜当前范围 / 搜索全部卡片」看起来像元数据而非按钮。
- 移出回顾的 toast 又把弹层里那句再说一遍，确认过后可更短。
