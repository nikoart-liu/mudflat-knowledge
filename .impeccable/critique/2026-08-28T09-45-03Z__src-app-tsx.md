## Priority Issues

### [P1] Filter state is not a sentence
- **What:** `只看星标` shares `.active` with location items. Content `h2` is `星标卡片` or `全部卡片` or the book name — never the tag set. Two sidebar rows can look selected at once.
- **Why it matters:** The returning reader cannot see “庄子 · 星标 · 方法论” without decoding the rail. Daily find-a-line leaks working memory.
- **Fix:** Make the header a query sentence. Give 只看星标 a toggle costume, not a nav-item costume. Show active tags in `head-meta`.
- **Suggested command:** `/impeccable clarify`

### [P1] Operate-the-card is hover theatre
- **What:** `.card-actions` and `.chip-del` are `opacity: 0` until hover/focus. Keyboard tabs through three extra stops per card plus every tag’s hidden ×. 10px chips miss 24px targets.
- **Why it matters:** Mouse users discover star/edit/delete late. Sam cannot scan. Alex cannot mark without aiming.
- **Fix:** Keep one always-visible pledge (star). Put edit/delete behind a single overflow, or reveal the row on the card without hiding it from the tab order. Make tag × a 24px target that is not opacity-0 in the accessibility tree.
- **Suggested command:** `/impeccable layout`

### [P1] Edits and reviews are too easy to commit or lose
- **What:** Modal mask `onClick={onClose}` drops unsaved 补写想法 / 新建. Review `flipOrAdvance` grades `'good'` with no skip, no Again, no `excludedFromReview` UI. Z only unflips. One mis-tap on the 420px `.deck-stage` is a log entry.
- **Why it matters:** High-stakes moments (keep this line / skip junk / finish a thought) have no emergency exit after the fact.
- **Fix:** Mask click does not discard dirty editors. Review: skip without grading, or undo last Good. Surface exclude-from-review. Shrink the hit target or require a second beat before Good.
- **Suggested command:** `/impeccable harden`

### [P2] Settings is not a stage; empty Review is a leftover label
- **What:** Review hides sidebar/search/sync. Settings keeps all of it, including a live search field that does not search Settings. Empty Review is a centered stack with a stray 「翻牌」 and 返回卡片墙 instead of the Key CTA the wall already knows.
- **Why it matters:** Two ideas of focus. First-timers who wander into 翻牌 get a dead end.
- **Fix:** Hide search (and maybe the shelf) on Settings. Empty Review uses the same Key CTA as the wall.
- **Suggested command:** `/impeccable distill`

### [P2] Empty library still wears a full workshop
- **What:** Search, disabled 同步, 只看星标, 标签/尚无标签, 「0 张」 — then the real invitation.
- **Why it matters:** First-run should be one path. This is a cabinet with every drawer labeled empty.
- **Fix:** Until first successful sync, hide search, 只看星标, and the tag zone. Leave 填写 API Key as the only loud control.
- **Suggested command:** `/impeccable onboard`
